# Open in Browser

Open the selected URL(s) in a specific browser. Select a URL, summon OpenClip,
and choose the browser you want to open it in.

## Browsers

- Arc
- Brave
- ChatGPT Atlas
- Chromium
- Comet
- DEVONagent Pro
- Dia
- DuckDuckGo
- Ecosia
- Google Chrome
- Helium
- iCab
- Microsoft Edge
- Mozilla Firefox
- Mullvad
- Opera
- Orion
- Quark
- Safari
- Shift
- Tor Browser
- Vivaldi
- Waterfox
- Zen

Each action appears only when the selection contains a URL. The action for the
browser you are currently in is hidden, so you won't see "Open in Safari" while
already in Safari.

## Download & Install

1. Download this repo as a zip: click the **`<> Code ▼`** button, then click
   **Download ZIP**. It will be downloaded as `OpenInBrowser.openclipext.zip`.
2. Open OpenClip, go to **Actions > Install Extension…**, and select
   `OpenInBrowser.openclipext.zip`.
3. Click **Enable** on the trust sheet to activate the extension.

## Notes

- If a browser isn't installed on your Mac, clicking its action shows a
  "Browser Not Available" toast.
- Icons are fetched from [Iconify](https://iconify.design) and require an
  internet connection to display.
